Bank Customer Database Modeling Project

This repository contains a database model representing a typical bank customer. It includes common banking elements such as various types of accounts, credit cards, and loans.

Project Contents:

Entity-Relationship Diagram (ERD):
- Visual representation of the database structure and the relationships between entities.

MS-SQL Script:
- SQL script to create and populate the database, including all tables, constraints, and relationships.

Database Documentation:
- Comprehensive documentation describing tables, columns, data types, constraints, and relationship logic.

Project Goals:
- To model a realistic and efficient database structure suitable for a banking application.
- To clearly define relationships among customers, accounts, loans, and credit cards.
- To implement this structure using MS-SQL syntax.
